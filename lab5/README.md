# Лабораторна робота №5 — Лендінг SaaS (TaskFlow)

**Тема:** Використання інтерфейсних бібліотек (PrimeVue). Створення плагінів у Vue.js.

**Продукт:** TaskFlow — менеджер задач для команди (SaaS).

---

## Кроки запуску проєкту

1. Встановити залежності:
   ```bash
   npm install
   ```
2. Запустити режим розробки:
   ```bash
   npm run dev
   ```
3. Відкрити в браузері адресу, яку покаже Vite (наприклад `http://localhost:5173`).

Збірка для продакшену:
```bash
npm run build
```

## Структура лендінгу

Реалізовані секції односторінкового лендінгу:

| Секція | Опис |
|--------|------|
| **Header** | Логотип (клік — копіювання назви) та навігація по якорях. |
| **Hero** | Заголовок, короткий опис, кнопка «Спробувати безкоштовно» (копіювання посилання). |
| **Проблема – Рішення** | Два блоки (Panel): проблема та рішення. |
| **Переваги** | Три картки (Card): дошки/списки, спільний доступ, звіти. |
| **Як це працює** | Нумерований список кроків. |
| **Тарифи / Плани** | Три плани (Basic, Team, Pro) у Card з ціною, списком можливостей і кнопкою «Обрати план». Під секцією — міні-калькулятор (InputNumber: кількість користувачів, орієнтовна вартість у грн/міс). |
| **Відгуки** | Дві картки з відгуками клієнтів. |
| **FAQ** | Три панелі (Panel) з toggleable. |
| **Контактна форма** | Форма «Напишіть нам» у Card: ім’я, email, телефон (InputMask), повідомлення (Textarea), чекбокс політики, кнопка «Надіслати». Валідація та Toast при успіху. |
| **Footer** | Копірайт та email (клік — копіювання). |

## Налаштування PrimeVue

- У `src/main.js` підключено:
  - `PrimeVue` з темою **Aura** (`@primeuix/themes/aura`).
  - `ToastService` для показу Toast.
- Стилі: `primeicons/primeicons.css`.
- Компоненти імпортуються локально в `App.vue`.

---

## Плагін CopyToClipboardPlugin

- **Файл:** `src/plugins/copyToClipboard.js`
- **Підключення:** у `main.js`: `app.use(CopyToClipboardPlugin)`.
- **API:** глобальна властивість `this.$copyToClipboard(text)`. Повертає `Promise<boolean>` (успіх копіювання).
- **Використання:** якщо `copy` повертає `true`, показується Toast з текстом «Скопійовано в буфер обміну».

**Місця виклику:**

1. **Header** — клік по логотипу «TaskFlow» → копіюється рядок `"TaskFlow"`.
2. **Hero** — клік по кнопці «Спробувати безкоштовно» → копіюється URL `"https://taskflow.demo/start"`.
3. **Тарифи** — кнопки «Обрати план» для Basic, Team, Pro → копіюється текст плану та ціна (наприклад «План Team — від 49 грн/міс за користувача»).
4. **Footer** — клік по email → копіюється `"support@taskflow.demo"`.
